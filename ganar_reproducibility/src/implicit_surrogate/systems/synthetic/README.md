# Synthetic System

Implements `z + kappa C.T tanh(C z) - q = 0` with `d=m=50`, rank `5`, and `kappa=0.8`. `C` has orthonormal rows, `F_z` is SPD, and the standardized nonlinear ground truth is `row(C D_q)`.

## Component contract

1. **Purpose:** provide the controlled regular implicit benchmark and its known nonlinear input subspace.
2. **Mathematical definition:** `F(z,q)=z+kappa C^T tanh(Cz)-q`, with analytic `F_z` and `F_q=-I`.
3. **Terminology:** `C` is the rank-5 nonlinear row basis; `kappa` controls nonlinearity.
4. **Inputs:** physical parameter `q` and optional state initial guess.
5. **Outputs:** physical state, residual, Jacobians, and true standardized subspace.
6. **Shapes:** `z,q,F` are `(50,)`; `C` is `(5,50)`; `F_z` is `(50,50)`.
7. **Physical units:** synthetic dimensionless units.
8. **Coordinate system:** fixed canonical row/column ordering generated by the benchmark seed.
9. **Numerical precision:** `float64` solve and derivative calculations.
10. **Public API:** `SyntheticImplicitSystem` and its residual/Jacobian/subspace methods.
11. **Dependencies:** NumPy and the common nonlinear solver interface.
12. **Invariants:** `F_z` is SPD for the frozen `kappa`; rank and dimensions remain fixed.
13. **Numerical verification:** residual/JVP checks and true-subspace overlap reference.
14. **Failure conditions:** nonconvergent Newton solve or nonfinite Jacobian.
15. **No-fallback rule:** no altered rank, kappa, or artificial output noise after freezing.
16. **Replacement interface:** compatible synthetic systems must expose the base system methods and metadata.
